# Richland County Information

A searchable, filterable directory of meaningful links across **Richland County, Ohio** (county seat: Mansfield) — government, education, health, business, community, recreation, and news.

## What's inside

```
RichlandCountyInformation/
├── react-app/                 # the Vite + React browsing app
│   └── src/data/links.js      # single source of truth for all links
├── data/
│   └── richland_county_links.csv   # the same directory as a spreadsheet
└── README.md
```

## Run it

```bash
cd react-app
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173/RichlandCountyInformation/).
